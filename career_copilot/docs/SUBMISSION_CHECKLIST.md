# Capstone submission checklist

- [ ] New Groq API key created; old key deleted
- [ ] `.env` NOT in the repo (`git ls-files | grep -i env` shows only `.env.example`)
- [ ] Tests pass: `python -m unittest discover -s tests`
- [ ] App runs locally with `streamlit run app.py`
- [ ] GitHub repo is public with README, architecture diagram, docs/ folder
- [ ] Repo description + topics added (genai, rag, llm, streamlit, ai-agent, groq, chromadb)
- [ ] Demo video recorded (3-4 min, see DEMO_SCRIPT.md) and link added to README
- [ ] App deployed on Streamlit Cloud (see DEPLOYMENT.md) and live URL added to README
- [ ] 3-4 screenshots saved in docs/ (chat with agent steps, ATS tab, job tracker)
- [ ] Final submission form: repo link, live link, video link
